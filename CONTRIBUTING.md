# Contributing to swift-log-sanitizer

## Requirements
- Swift 6.0+
- macOS 14+ / iOS 17+

## Development
```bash
swift build
swift test
```

## Pull Requests
1. Fork the repository
2. Create a feature branch
3. Ensure all tests pass
4. Submit a pull request
